What the data says

Competitive in places. Behind in others.

The useful result is the shape of performance, not a winner badge. Nift is already competitive with mainstream scripting runtimes on a number of workloads, while Lua/LuaJIT and Python still expose clear optimization targets.

01

Loops

Large warm: Nift 38.5 ms, Ruby 43.3 ms, Node 91.3 ms, Python 19.7 ms, Lua 5.4 2.7 ms.

02

Function calls

Large warm: Nift 61.5 ms, Ruby 45.5 ms, Node 87.6 ms, Python 19.7 ms, LuaJIT 4.6 ms.

03

BFS

Large warm: Nift 265.6 ms versus Python 53.7 ms and Ruby 76.3 ms. This remains an obvious area for future work.

Benchmark families

From startup to real work.

The suite separates cold-start behaviour, algorithms, structured data, filesystems and shell work so one workload cannot masquerade as overall language performance.

01

Algorithms

Loops, calls, arrays, strings, dynamic programming, graphs and search.

02

Data & collections

JSON parsing, querying, mutation and transforms plus maps, sets and string-heavy work.

03

Practical scripting

Filesystem traversal, shell-oriented tasks and startup-sensitive work.
