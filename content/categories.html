Workload taxonomy

Categories

Different workloads expose different runtime characteristics. Results stay separated by category before any aggregate view is considered.

01

Startup & fundamentals

No-op startup, arithmetic, loops, calls, strings and allocation.

02

Arrays & strings

Scanning, transforms, frequency maps, two-pointer and sliding-window tasks.

03

Dynamic programming

Coin change, LCS, edit distance, knapsack, LIS, grids and interval DP.

04

Graphs & search

BFS, DFS, topological ordering, shortest paths and traversal-heavy work.

05

Structured data

JSON parsing, querying, transformation, maps, sets and collection pipelines.

06

Filesystem

Traversal, globbing, filtering, file metadata and copy/move workloads.

07

SQLite

Queries, inserts, transformations and data-to-database workflows.

08

Mixed scripting

Representative maintenance jobs combining files, data and databases.

09

Shell tasks

Tasks where Bash and command-line composition provide a meaningful comparison.
